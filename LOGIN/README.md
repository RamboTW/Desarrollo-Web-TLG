# 🔐 Login con efecto Glassmorphism

Interfaz moderna de inicio de sesión desarrollada con **HTML, CSS y JavaScript**. El diseño utiliza un fondo fotográfico, transparencias, desenfoque y animaciones suaves para crear un estilo visual elegante y atractivo.

## ✨ Características

- Diseño moderno con efecto **Glassmorphism**.
- Fondo de pantalla adaptable.
- Campos de usuario y contraseña con etiquetas animadas.
- Íconos integrados mediante **Font Awesome**.
- Botón de inicio de sesión con efectos al pasar el cursor.
- Validación básica de campos obligatorios.
- Simulación de verificación al enviar el formulario.
- Mensaje de bienvenida personalizado con el nombre de usuario.
- Diseño centrado y adaptable a diferentes tamaños de pantalla.

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Google Fonts**
- **Font Awesome**

## 🚀 Funcionamiento

1. El usuario ingresa su nombre y contraseña.
2. Al presionar **Sign In**, el botón cambia temporalmente a **Verifying...**.
3. Después de una breve espera, aparece un mensaje de bienvenida.
4. El formulario se limpia y queda listo para volver a utilizarse.

## ▶️ Cómo ejecutarlo

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en un navegador moderno.
3. También puedes ejecutarlo con la extensión **Live Server** de Visual Studio Code.

## ⚠️ Importante

Este proyecto representa únicamente una interfaz visual de inicio de sesión. La autenticación es simulada con JavaScript y no está conectada a una base de datos ni a un servidor.

Para utilizarlo en un sistema real sería necesario implementar un backend seguro, almacenamiento de usuarios, cifrado de contraseñas y validación de credenciales.
