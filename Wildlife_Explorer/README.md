# 🦌 Explorador de Vida Silvestre

Una experiencia web interactiva diseñada para descubrir el mundo animal de una forma visual, dinámica y atractiva.

**Explorador de Vida Silvestre** presenta diferentes animales mediante un carrusel animado con imágenes, descripciones y miniaturas seleccionables. El proyecto combina diseño moderno, navegación sencilla y contenido informativo en una sola página.

## ✨ Funcionalidades principales

- Carrusel automático de animales.
- Navegación mediante flechas.
- Selección directa desde las miniaturas.
- Información breve sobre cada animal.
- Sección informativa sobre la naturaleza.
- Formulario de contacto.
- Ventana emergente de suscripción.
- Animaciones y transiciones suaves.
- Diseño adaptable para computadoras, tablets y celulares.

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

## 🎮 Cómo utilizarlo

1. Usa las flechas para avanzar o retroceder entre los animales.
2. Selecciona una miniatura para mostrar una imagen específica.
3. Presiona **Ver más** para consultar la sección informativa.
4. Utiliza **Suscribirse** para abrir el formulario de suscripción.
5. Accede a la sección de contacto para enviar un mensaje.

## ▶️ Ejecución

Descarga o clona este repositorio y abre el archivo `index.html` en un navegador moderno.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto localmente.

## 🌿 Objetivo del proyecto

Este proyecto fue creado para presentar información sobre distintos animales mediante una interfaz llamativa e interactiva, combinando contenido visual, animaciones y una navegación sencilla.
