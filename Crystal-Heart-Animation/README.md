# Crystal Heart Animation 💖

Proyecto web interactivo que presenta una animación de un corazón de cristal en 3D, acompañado de música, partículas brillantes y una lluvia de corazones y estrellas. Desarrollado con JavaScript, Three.js y tecnologías web modernas.

## ✨ Características

- Animación de un corazón de cristal en 3D con movimiento y rotación.
- Efectos de partículas que forman un corazón luminoso.
- Lluvia animada de corazones y estrellas.
- Reproducción de música al hacer clic en el botón central.
- Animaciones y efectos visuales sincronizados con el audio.
- Interfaz con temática romántica y colores oscuros.
- Diseño adaptable a computadoras y dispositivos móviles.
- Interacción mediante mouse o pantalla táctil.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Three.js
- WebGL y GLSL Shaders
- GSAP
- Netlify

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Ejecuta un servidor local desde la terminal:

   ```bash
   python3 -m http.server 5500
   ```

4. Accede desde tu navegador a `http://localhost:5500`.
5. Presiona el botón musical para iniciar la animación acompañada de música.

**Nota:** El proyecto utiliza recursos externos y requiere conexión a Internet para cargarlos correctamente.
