# 🪐 Explorador del Sistema Solar

Una experiencia web interactiva para recorrer el sistema solar y conocer sus planetas de una forma visual, dinámica y atractiva.

El proyecto permite seleccionar diferentes cuerpos celestes, observar sus animaciones, consultar información básica y acompañar la navegación con música y efectos de transición.

## ✨ Características

- Exploración interactiva de los planetas del sistema solar.
- Menú lateral para seleccionar cada planeta.
- Representación visual de Mercurio, Venus, Tierra, Marte, Júpiter, Saturno, Urano, Neptuno y Plutón.
- Información descriptiva de cada cuerpo celeste.
- Visualización de lunas y trayectorias en varios planetas.
- Animaciones y transiciones creadas principalmente con CSS.
- Música ambiental con botón de reproducción y pausa.
- Efecto de sonido al cambiar de planeta.
- Diseño espacial llamativo para una experiencia más inmersiva.

## 🎮 Cómo utilizarlo

1. Selecciona un planeta desde el menú lateral.
2. Observa la animación y la información mostrada en pantalla.
3. Presiona el botón con el ícono de galaxia para activar o pausar la música.
4. Cambia entre los planetas para escuchar el efecto de viaje espacial.

## ▶️ Cómo ejecutarlo

1. Descarga o clona este repositorio.
2. Verifica que los archivos de audio se encuentren en la carpeta correspondiente.
3. Abre el archivo `index.html` en un navegador moderno.

También puedes ejecutarlo con la extensión **Live Server** de Visual Studio Code para obtener una mejor experiencia.

## 🌌 Propósito

Este proyecto fue creado para presentar el sistema solar de una forma entretenida e interactiva, combinando información astronómica, animaciones visuales y efectos de sonido en una sola página web.
