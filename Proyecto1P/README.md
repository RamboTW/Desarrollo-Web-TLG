# 📘 EnglishPro — Proyecto del Primer Parcial

**EnglishPro** es un sitio web educativo desarrollado como proyecto del primer parcial de la asignatura **Desarrollo de Aplicaciones Web**.

La plataforma presenta una propuesta visual para ofrecer cursos de inglés, mostrar información sobre el servicio y permitir que los visitantes conozcan los planes disponibles. El proyecto fue construido únicamente con **HTML, CSS y JavaScript**, sin utilizar backend ni base de datos.

## 🎯 Objetivo del proyecto

Diseñar una página web moderna, organizada y adaptable que permita presentar una academia de inglés de manera clara y atractiva.

El proyecto busca aplicar conocimientos fundamentales de desarrollo web, como la estructura semántica de páginas, estilos responsivos, navegación entre secciones e interactividad mediante JavaScript.

## ✨ Características principales

- Página principal con presentación de EnglishPro.
- Sección visual con imágenes relacionadas con el aprendizaje del inglés.
- Página informativa sobre la plataforma y sus servicios.
- Página dedicada a los precios y planes disponibles.
- Menú de navegación entre las distintas páginas.
- Diseño adaptable para computadoras, tablets y dispositivos móviles.
- Modo claro y oscuro.
- Conservación del tema seleccionado mediante `localStorage`.
- Menú responsive para pantallas pequeñas.
- Uso de efectos visuales, tarjetas y botones interactivos.
- Interfaz desarrollada completamente del lado del cliente.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos, animaciones y adaptación responsive.
- **JavaScript:** interactividad, menú móvil y cambio de tema.
- **Normalize.css:** normalización de estilos entre navegadores.

## 📄 Descripción de las páginas

### `index.html`

Página principal del proyecto. Contiene la presentación de EnglishPro, la navegación principal, contenido destacado e imágenes relacionadas con los cursos de inglés.

### `info.html`

Página destinada a explicar la propuesta de EnglishPro, su propósito y la información relacionada con el aprendizaje del idioma.

### `precios.html`

Página que presenta los diferentes planes, precios y beneficios disponibles para los estudiantes.

## 🎨 Diseño e interactividad

El proyecto utiliza una identidad visual moderna basada en tonos azules, fondos claros y componentes organizados mediante tarjetas.

JavaScript permite controlar elementos interactivos como el menú responsive y el cambio entre modo claro y oscuro. La preferencia del usuario se guarda en el navegador para mantener el tema seleccionado al volver a cargar la página.

## ▶️ Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Ejecuta el archivo `index.html` en un navegador.
4. También puedes utilizar la extensión **Live Server** para visualizar el sitio localmente.

No es necesario instalar dependencias ni configurar una base de datos.
