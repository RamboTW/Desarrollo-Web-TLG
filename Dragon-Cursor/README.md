# Dragón que sigue al cursor 🐉

Proyecto web que presenta una animación interactiva de un dragón construido con gráficos SVG. El dragón sigue el movimiento del cursor con un desplazamiento fluido y ondulante, desarrollado con HTML, CSS y JavaScript puro.

## Características

- Dragón animado que sigue el movimiento del cursor.
- Cuerpo articulado formado por segmentos que se desplazan de manera coordinada.
- Movimiento ondulante y automático mediante funciones trigonométricas.
- Gráficos vectoriales SVG con degradados en las aletas y espinas.
- Animación continua con `requestAnimationFrame()`.
- Visualización adaptable al tamaño de la ventana del navegador.
- Compatible con eventos de puntero, como mouse y pantallas táctiles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- SVG (Scalable Vector Graphics)

## Cómo ejecutar el proyecto

1. Abre la carpeta del proyecto en Visual Studio Code.
2. Instala la extensión **Live Server** si todavía no la tienes.
3. Haz clic derecho sobre `index.html`.
4. Selecciona **Open with Live Server**.
5. Mueve el cursor dentro de la página para interactuar con el dragón.

También puedes abrir `index.html` directamente en un navegador. No se necesita conexión a internet ni instalar librerías externas.

## Uso

Mueve el mouse por la pantalla y observa cómo el dragón sigue el cursor mientras su cuerpo se curva de forma natural. Si dejas de moverlo, la animación continúa con un movimiento ondulante.
