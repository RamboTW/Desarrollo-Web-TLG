# 🌌 Galaxia del Amor 💖

Una experiencia web interactiva creada para transformar sentimientos en un pequeño universo digital.

**Galaxia del Amor** presenta una escena espacial en 3D llena de estrellas, luces, anillos brillantes y mensajes románticos que orbitan alrededor de un núcleo central con la frase **“TE AMO ❤️”**.

## ✨ Sobre el proyecto

Este proyecto combina programación, animación y diseño visual para crear una dedicatoria diferente, llamativa y especial.

El usuario puede explorar la galaxia, mover la cámara, acercarse o alejarse y acompañar la experiencia con música mediante un reproductor personalizado.

## 🚀 Funcionalidades

- Galaxia interactiva en 3D.
- Fondo espacial con miles de estrellas.
- Núcleo central animado con efecto de latido.
- Mensaje principal **“TE AMO ❤️”**.
- Frases románticas distribuidas alrededor de la galaxia.
- Anillos luminosos y efectos de brillo.
- Movimiento de cámara con el mouse o la pantalla táctil.
- Zoom con la rueda del mouse o gesto de pellizco.
- Reproductor de música con botón de reproducción y barra de progreso.
- Compatibilidad con computadoras y dispositivos móviles.

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Three.js**
- **WebGL**

## 🎮 Controles

### En computadora

- Mantén presionado y arrastra el mouse para girar la vista.
- Usa la rueda del mouse para acercarte o alejarte.
- Presiona el botón de reproducción para escuchar la música.
- Haz clic sobre la barra del reproductor para cambiar el momento de la canción.

### En dispositivos móviles

- Desliza el dedo para mover la cámara.
- Usa dos dedos para controlar el zoom.
- Utiliza el reproductor inferior para iniciar o pausar la música.

## ▶️ Cómo visualizarlo

1. Descarga o clona este repositorio.
2. Coloca una canción con el nombre `mi-cancion.mp3` junto al archivo principal.
3. Abre `index.html` en un navegador moderno.

También puedes ejecutarlo con la extensión **Live Server** de Visual Studio Code para obtener una mejor experiencia.

## 💌 Propósito

Este proyecto fue creado como una forma creativa de expresar amor mediante la tecnología, convirtiendo palabras y emociones en una experiencia visual, musical e interactiva.
